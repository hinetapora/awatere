## Building now

**[PayStage](https://paystage.xyz)** — the check that runs before an AI agent pays. An independent, read-only
preflight for x402: `pay`, `review` or `do_not_pay` with the rule that fired, plus a receipt for every decision.
*In plain words:* your AI assistant can buy things on its own; this checks each purchase against the rules you
set — per purchase, per day, who it may buy from — and stops it if it doesn't fit. Like a company card with a
limit, except the limit is actually checked every time and you get a receipt.

Open source, no custody, built on Base.

**[VouchGuard](https://vouchguard.app)** — the same limits in a form a person can hold. A spending mandate on an
Apple Wallet pass: per-purchase cap, per-24h ceiling, expiry and revoke. *In plain words:* the same limits on a card in your phone's wallet — see what each assistant may spend, change it,
switch it off. A ticket you carry, not a dashboard you have to remember.

A record of authority, not a payment card.
